# SMOAC brand assets

Official mark and wordmark for reuse across the product.

| File | Use |
|------|-----|
| `smoac-mark.png` | Icon mark (S + spark) — transparent |
| `smoac-wordmark.png` | SMOAC letterforms — transparent |
| `smoac-mark-source.png` | Original mark plate (black bg) |
| `smoac-wordmark-source.png` | Original wordmark plate (black bg) |

Site copies also live at `/public/smoac-mark.png` and `/public/smoac-wordmark.png` (wired via `src/lib/brand.ts`).

The wordmark **is** the custom SMOAC type. There is no separate `.ttf`/`.otf` yet — logo lockups and `SmoacBrandName` use this raster. Body/SEO copy stays plain “SMOAC” text.
